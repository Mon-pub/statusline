🔧 claude-statusline — شريط حالة متقدم لـ Claude Code

شريط حالة غني بالألوان والمعلومات لأداة Claude Code، مفتوح المصدر بالكامل (MIT).
مُحدَّث لإصدار Claude Code 2.1.261 (سبتمبر 2026).

━━━━━━━━━━━━━━━━━━━━

✨ المميزات الرئيسية:

📊 عرض متعدد الأسطر بألوان ANSI
شريط تقدم ملوّن ●●●●○○○○ للسياق وحدود الاستخدام
اسم الموديل + مستوى الجهد (effort) + شارات fast / no-think
فرع git الحالي ورقم الـ PR واسم الـ worktree

🧠 تفصيل ما يملأ نافذة السياق
fill: tool out 69% · tool cmd 17% · attached 13% · chat 1%
لتعرف بالضبط ما الذي يستهلك السياق وما الذي يمكن تقليصه

⚡ حالة ذاكرة التخزين المؤقت (prompt cache)
cache 92% · 1h warm 59m — عدّاد تنازلي حتى تبرد الذاكرة المؤقتة
أخضر / أصفر / أحمر حسب الوقت المتبقي — يذكّرك بإرسال الدور التالي قبل انتهاء الصلاحية

📈 حدود الاستخدام مع أشرطة تقدم
نافذة 5 ساعات + 7 أيام + حد الإنفاق (spend limit)
شريط أسبوعي لكل موديل على حدة: 7d Fable: ●●○○○○○○○○ 22% — نفس رقم "Current week (Fable)" في /usage
أوقات إعادة التعيين بصيغة مقروءة: "5:00pm (3h16m)"
🔥 توقّع الوصول للحد: ->cap 1h27m (Sat 03:02) عندما تكون وتيرة الاستهلاك ستصل للسقف قبل إعادة التعيين

💰 تتبع تكلفة الجلسة لحظياً
التكلفة الرسمية من Claude Code + معدل الحرق $/h + مدة الجلسة + الأسطر المضافة/المحذوفة
تسعير دقيق لكل موديل وإصدار (Fable 5.1 / Opus 5.5 / Opus 5 / Sonnet 5.5 / Sonnet 5 / Haiku) بما فيه وضع fast

💾 نظام نسخ احتياطي تلقائي للسياق
نسخ احتياطي عند 50k توكن ثم كل 10k، وعند عتبات 30% / 15% / 5% متبقية
نسخ قبل ضغط السياق (PreCompact) وعند نهاية الجلسة (SessionEnd)
ضغط النسخ القديمة تلقائياً عبر Claude CLI

📉 مساحة حرة حقيقية
يحسب المساحة المتبقية بعد خصم buffer الضغط التلقائي (33k)

📋 أدوات إضافية
تقرير تكلفة شامل لكل المشاريع مع فلتر بالتاريخ
تفصيل التكلفة حسب الموديل والإصدار

🧪 اختبارات ذاتية
bash tests/run.sh — يفحص العرض والتسعير والنسخ الاحتياطي والمدخلات الخبيثة

━━━━━━━━━━━━━━━━━━━━

🛠 المتطلبات: bash 4+ و jq و node 18+
📦 التثبيت: أمر واحد ./install.sh
⚙️ أداء: قراءة واحدة بـ jq لكل تحديث (~45ms)
🔒 الخصوصية: بدون اتصال بالإنترنت، بدون تتبع
